Este repositorio documenta mi progreso y proyectos realizados durante el reto de aprendizaje intensivo de JavaScript. Aquí encontrarás desde los conceptos fundamentales hasta la manipulación avanzada del DOM y consumo de APIs.

## 📂 Estructura del Aprendizaje

El repositorio está organizado por niveles de dificultad y días de práctica:

```text
20-Dias-JS/
├── 01-Fundamentos/    # Días 1-5
│   ├── index.html
│   └── script.js
├── 02-Intermedio/     # Días 6-14 (JSON, Eventos, APIs)
└── 03-Avanzado/       # Días 15-20 (Async, Frameworks, Storage)
```

## 📚 Contenido del Curso

### 🔹 Fundamentos (Días 1-5)
En esta etapa inicial se establecen las bases del lenguaje y su integración con la web:

- **Conexión:** Integración entre archivos HTML, CSS y JS.
- **Sintaxis:** Estructura básica y tipos de datos.
- **DOM:** Introducción a la manipulación del *Document Object Model*.

### 🔸 Nivel Intermedio (Días 6-14)
Profundización en la lógica de programación y dinamismo web:

- **Manejo de Eventos:** Interacción del usuario (clicks, inputs).
- **JSON:** Estructura de datos y manipulación de archivos `.json`.
- **Lógica:** Uso de condicionales e iteradores avanzados (`map`, `filter`).
- **DOM Avanzado:** Creación de elementos dinámicos.
- **APIs:** Consumo de datos externos usando `fetch`.

### 🚀 Nivel Avanzado (Días 15-20)
Conceptos complejos y arquitectura moderna:

- **Asincronía:** Programación asíncrona, *Promises* y *Async/Await*.
- **Persistencia:** Uso de `LocalStorage` y `SessionStorage`.
- **Módulos:** Importación y exportación de archivos (ES Modules).
- **Introducción a Frameworks:** Primeros pasos con conceptos de Angular y React.
- **Integración:** Conexión básica con Bases de Datos (SQL).
